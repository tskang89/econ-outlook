# 주요국 성장·물가 전망

<https://tskang89.github.io/econ-outlook/>

조간 브리핑 참고자료에 걸리는 쪽이다. 아홉 나라의 실질 GDP 성장률과 소비자물가
상승률을 **과거 3개년 실적 + 올해·내년 전망** 다섯 해로 싣는다. 월요일에 한 번
확인하되 **새 전망이 나왔을 때만** 쪽을 다시 쓴다.

## 출처가 나라마다 다르다

섞어 쓴 것이 아니라 각 나라를 가장 잘 아는 곳을 고른 것이다. 화면의 국가 이름
아래에 출처를 적는다.

| | 출처 | 받는 법 |
|---|---|---|
| 유로지역·독일·프랑스·이탈리아·스페인 | EU 집행위 | AMECO 데이터베이스 |
| 미국·중국·일본 | IMF World Economic Outlook | DataMapper |
| 한국 | 한국은행 경제전망 | 보도자료 본문 |

한국의 **과거 실적**은 IMF 값을 쓴다. 전망 두 해만 한국은행 값으로 덮는다.

## 한국은행 전망을 어떻게 캐내는가

세 번 막히고 네 번째에 길이 났다(2026-10-06).

| 시도 | |
|---|---|
| 보도자료 **목록** 긁기 | 자바스크립트로 그려진다. requests 로는 글이 한 건도 안 보인다 |
| RSS | 없다. `rss.do` 는 500 |
| PDF 첨부 열기 | 필요 없다 — **본문에 숫자가 그대로 있다** |
| **관련 뉴스/자료 타고 가기** | 서버가 그려 보낸다. 이것이 길이다 |

글 본문은 서버가 다 그려 보내고, 글마다 아래에 '관련 뉴스/자료'가 붙는데 거기에
**더 새 글 번호**가 들어 있다. 아는 글 하나를 닻으로 삼아 타고 올라가면 최신
전망에 닿는다. 찾은 번호는 `data/state.json` 에 적어 두어 다음 빌드의 닻이 된다.

문구가 판마다 다르다. 둘 다 받는다.

```
2025년 11월   GDP성장률 금년 1.0%, 내년 1.8%  /  소비자물가 … 금년, 내년 모두 2.1%
2026년 8월    국내경제는 올해 3.3%, 내년 2.9%  /  소비자물가는 올해 2.7%, 내년 2.3%
```

## 매주 새로 그리지 않는다

수치와 판(vintage)을 `data/state.json` 에 적어 두고 지난주와 같으면 쪽을 건드리지
않는다. 날짜만 바뀐 쪽이 올라오면 '새 전망이 나왔나' 싶어 열어 보게 된다.
커밋도 바뀐 주에만 남아, 되돌아보면 언제 전망이 바뀌었는지가 한눈에 보인다.

## 알아 둘 것

**AMECO 는 수준 계열만 준다.** 성장률·물가상승률은 전년비로 계산한 것이라 집행위
공표 숫자와 끝자리 반올림이 다를 수 있다. 같은 계열에서 낸 것이라 값이 어긋나지는
않는다. IMF·한국은행은 상승률을 그대로 싣는다.

**물가의 정의가 조금씩 다르다.** 유로 쪽은 HICP, 나머지는 각국 소비자물가다.

## 돌리기

```
pip install -r requirements.txt
python build/make.py           # 바뀌었을 때만 index.html 을 새로 쓴다
python build/make.py --force   # 같아도 새로 쓴다
python build/make.py --check   # 쓰지 않고 만들어만 본다
```

## 짜임

```
build/ameco.py   EU 집행위 (zip 안의 장별 TXT, 수준 → 전년비)
build/imffc.py   IMF WEO (상승률 그대로)
build/bokfc.py   한국은행 (닻에서 타고 올라가 본문 파싱)
build/make.py    표 만들기 · 변경 감지
template.html    틀
data/state.json  지난 판의 수치 지문과 한국은행 닻
```

한 출처가 실패해도 나머지는 올라가고, 빠진 것은 화면에 적는다.
